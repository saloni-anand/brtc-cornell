# Big Red Tech Club — Communications Hub

A single-file communications hub for the Cornell Tech MBA Big Red Tech Club (BRTC): events, newsletters, speakers, career resources, polls, and ways to get in touch.

## Run it locally

No build step. Open `index.html` in a browser.

## Contributing

1. Fork the repo (or create a branch if you have write access).
2. Edit `index.html` — styles, markup, and scripts are all in this one file.
3. Open `index.html` in your browser to check your changes.
4. Commit and open a pull request.

## Content guidelines

- Only add real, confirmed content (events, links, speakers). No placeholder data.
- Don't commit personalized tracking links (e.g. `member_id` tokens) — use generic URLs only.
